# Issue #19：安全断开宿主及其控制台

## 目标

把主机连接页的远程主按钮改为每台宿主独立的连接/断开入口。主动断开必须以目标 `HostId` 为边界：写操作期间禁止断开；有控制台窗口时先确认并只关闭目标宿主窗口；成功后停止目标刷新与重连、释放连接并移除目标 VM 分组，同时保留保存的主机配置。

## 已确认测试边界

- `IHostSessionRegistry`：断开可用性、准备、取消和提交均按 `HostId` 路由，并与写租约原子协调。
- 多宿主隔离：断开 A 不改变本机或 B 的会话、写租约、控制台与 VM 分组。
- 控制台生命周期：窗口按宿主和 VM 登记，重复打开激活已有窗口，关闭时可靠注销。
- 交互事务：无控制台直接断开；有控制台显示数量和影响范围；取消确认零副作用。
- 主机连接页：主按钮仅显示“连接到此主机”“正在连接”或“断开”，断开禁用原因只通过 Tooltip 表达。
- VM 页面：注册表移除远程宿主后只移除目标组并取消其刷新；本机组始终保留。

## 交付范围

1. 为多宿主注册表补齐每宿主断开准备事务和写计数状态通知。
2. 新增窄控制台窗口注册表，并接入 `Navigation` 与窗口关闭生命周期。
3. 新增断开交互协调器，覆盖直接断开、确认、取消和目标窗口关闭失败。
4. 接入主机连接页按钮文字、可用性与 Tooltip。
5. 接入 VM 页面目标远程组移除和刷新取消。

## 非目标

- 不删除保存的主机配置或 Windows 凭据。
- 不实现跨宿主批量断开。
- 不实现实时日志或设置修复；属于 #20/#21。
- 不升级 `SSH.NET` 或处理既有构建警告。
- 不对 `10.0.0.6` 执行真实断开、断网、VM 写入或故障注入。

## 验收

- 写租约存在时，目标宿主断开按钮置灰并显示中文原因；其他宿主不受影响。
- 无目标控制台时直接断开；有目标控制台时确认后只关闭目标窗口并断开。
- 取消确认不关闭窗口、不停止重连、不移除会话或分组、不改变选择。
- 主动断开停止目标刷新/重连并释放连接，目标 VM 分组被移除，本机与其他远程组保持。
- 保存配置保留，主按钮可再次显示“连接到此主机”。
- 确定性测试、Release 构建、UTF-8 无 BOM、凭据模式和差异检查通过。
