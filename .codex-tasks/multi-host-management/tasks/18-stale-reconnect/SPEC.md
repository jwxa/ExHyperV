# Issue #18：单宿主旧数据与独立自动重连

## 目标

一台远程宿主意外掉线时，只冻结该宿主并保留最后成功的 VM 数据；本机和其他远程宿主继续工作。每台远程宿主使用独立、唯一、可取消且退避封顶的重连循环，用户可以只对选中宿主立即重试或停止重连。

## 已确认测试边界

- `IHostSessionRegistry`：连接丢失、停止、立即重试和恢复必须按 `HostId` 路由。
- 多宿主隔离：A 重连中时 B 的 stamp、管理读取、写租约和控制台捕获仍有效。
- 并行重连：A/B 可以同时各有一个重连任务，任一宿主恢复不改变另一宿主状态。
- VM 分组：应用旧数据快照不能清空现有 VM；旧数据状态使用现有黄色状态视觉并提供中文 Tooltip。
- 恢复：成功后只递增目标宿主代次，清除旧数据标记并重新计算能力；VM 页面收到新快照后刷新目标组。

## 交付范围

1. 为多宿主注册表补齐目标宿主掉线、重复报告、独立读写和控制台门禁的行为覆盖。
2. 覆盖每宿主唯一重连任务、A/B 并行重连、目标宿主立即重试与停止。
3. 在 VM 分组标题上明确表达“旧数据/正在重连/重连已停止”，复用现有状态色并通过 Tooltip 给出原因。
4. 保持已有封顶退避、取消、候选释放和敏感信息脱敏逻辑不变。

## 非目标

- 不实现主动断开或移除宿主分组；属于 #19。
- 不重做重连算法或新增持久化恢复；遵循 YAGNI。
- 不实现实时日志和设置修复；属于 #20/#21。
- 不执行真实断网、远程配置、VM 写入或其他故障注入。

## 验收

- A 掉线后，A 保留旧快照和 VM，写操作与控制台被禁用；B 仍可读写和打开控制台。
- 重复的 A 掉线报告不启动第二个任务；A/B 可各自同时重连。
- 立即重试和停止只影响指定宿主；停止后仍保留旧数据，不切回本机、不移除分组。
- A 恢复后只推进 A 的代次和能力，B 的 stamp 继续有效。
- 确定性测试、Release 构建、UTF-8 无 BOM、凭据模式和差异检查通过。
