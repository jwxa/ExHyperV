## 已确认边界

- `AppLog` 是唯一原始日志入口；脱敏后的同一不可变条目分发到磁盘和实时 Feed。
- Feed 按 `HostId` 维护快照与订阅；无宿主上下文的应用日志归本机/应用范围。
- 每宿主默认保留最近 2,000 条，磁盘滚动容量不受内存上限影响。
- UI 只订阅当前选中宿主，选择切换必须使旧订阅失效。
- 滚动状态属于视图交互，不由 Feed 猜测用户阅读位置。
- 不执行真实远程配置、VM 写入或故障注入。
